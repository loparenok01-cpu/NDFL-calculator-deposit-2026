# Запуск материалов

Шаблон кейса и заполненный референс — обычные HTML-файлы, без сервера
и без сборки.

## Как открыть

Откройте `case-template.html` и `reference-example.html` двойным
щелчком (или File → Open в браузере) — оба используют один и тот же
`style.css`.

## Что нужно сделать

1. Откройте `reference-example.html` — это заполненный пример кейса
   («Трекер расходов «Кошелёк»»), посмотрите, какого объёма и глубины
   должны быть блоки.
2. Откройте `case-template.html` — это шаблон с 5 секциями и
   подсказками в квадратных скобках `[...]` вместо текста.
3. Замените весь текст в квадратных скобках на информацию о вашем
   собственном проекте — не удаляйте структуру секций.
4. Замените три блока `.img-placeholder` в разделе «Результат» на
   реальные скриншоты вашего проекта (`<img src="...">`).
5. Проверьте ссылку на проект и почту в блоке «Связаться со мной» —
   должны вести на реальный проект и реальный контакт.

Обязательные блоки, которые должны быть заполнены (ничего не
пропускайте): задача, целевая аудитория, проблема, решение, основные
функции, использованные инструменты, результат, изображения, ссылка
на проект.

Файлы:

- `case-template.html` — шаблон для заполнения (основной файл для работы)
- `reference-example.html` — заполненный пример для ориентира
- `style.css` — общие стили обоих файлов — менять не обязательно, но можно адаптировать под себя
