Задача и контекст

Задача

Сделать простое веб-приложение, где можно быстро вносить траты и видеть, на что уходят деньги за месяц.

Целевая аудитория

Люди, которые хотят начать вести бюджет, но не готовы разбираться со сложными приложениями или таблицами.

Проблема

Большинство трекеров расходов перегружены функциями — банки, синхронизация, аналитика — а нужен просто быстрый способ записать трату и увидеть итог по категориям.

Решение

Решение

Одностраничное веб-приложение: одна форма для добавления траты (сумма + категория) и диаграмма расходов по категориям за месяц.

Основные функции

Добавление траты в 2 клика, 6 готовых категорий, круговая диаграмма расходов, сброс/начало нового месяца.

Использованные инструменты

HTML/CSS/JavaScript, Chart.js для диаграммы, localStorage для хранения данных, Claude Code для написания и отладки кода.

Результат

Рабочее приложение, которым автор пользуется сам уже 2 месяца: занесение траты занимает 5 секунд, а диаграмма сразу показывает, на какую категорию уходит больше всего денег.
